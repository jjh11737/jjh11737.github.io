记录一下我用tmux一些容易忘的点，借鉴[a quick&easy guide](https://hamvocke.com/blog/a-quick-and-easy-guide-to-tmux/) / [cheat Sheet](http://tmuxcheatsheet.com/)

> 为什么用Tmux？
>
> 1. 服务器：比如你通过ssh连接到远程服务器上，如果连接断开，tmux当然会断联，但是仅此而已，这个会话包括所有相关进程仍然会在服务器后台执行，你只需要重新ssh一下然后连接到那个会话即可
> 2. 本地：同上。总之有2个强大的功能：
>    - 终端里面的窗口管理
>    - 会话管理

首先需要明确tmux有3个基本概念：

- session：一整组窗口，会话的载体，ssh断了它也不死
- window：就是一整面
- panel：window里切出来的一块



Session：

1. 创建一个session，只需要`tmux`即可：

   > 当然也可以是`tmux new` / `tmux new-session`

   ![image-20260907091507765](https://raw.githubusercontent.com/jjh11737/jjh-blog-images/master/imgs/image-20260907091507765.png)

> 左下角：`[0] 0:bash*`：`[0]`代表当前所在窗口编号，后面是每个窗口的前台进程

2. 创建新会话 / 连接到既有的会话：`tmux new-session -A -s <名字>`，没有就新建，有了就直接连上去，我觉得这是最省事的一条

   - 列出所有会话：`tmux ls`
   - 连上去：`tmux attach -t <名字>`，`-d`可以先踢掉别处的连接
   - 在会话里断开（进程继续跑）：`prefix d`
   - 重命名当前会话：`prefix $`
   - 杀掉：`tmux kill-session -t <名字>`

- 创建一个新的窗口：一旦我们处于一个session里面时，就可以`prefix c`创建一个新的窗口。
  ![image-20260907092327661](https://raw.githubusercontent.com/jjh11737/jjh-blog-images/master/imgs/image-20260907092327661.png)

> 和emacs一样，这里使用命令也是有一个prefix：`<C-b>`

- 窗口间来回切换：`prefix n`到下一个窗口
  				`prefix  0/1/...9`指定编号的切换
- 关闭窗口：`prefix &`关闭当前窗口
- panel：
  - 创建小的panel：`prefix %`创建横向的一个新的panel小窗口
                                 `prefix "`创建纵向的一个新的panel
  - 关闭小的panel：`C-d`关闭当前的panel

算了这些看手册也有，我就整理我碰到的平常有用的：

- `prefix z`：将当前panel全屏，再输一次就是退出全屏
- `prefix l`：回到上一个window
- `prefix w`：看window的树
- `prefix o`：在panel之间顺序跳（`prefix`加方向键是按方向跳），`prefix q`显示编号让你按数字跳
- `prefix [`：进copy mode，可以用vim的键位翻历史、选中，`prefix ]`粘贴
- `prefix ,`改窗口名字
    `prefix $`改会话名字
- `prefix ?`：列出所有键位

## 配置和插件

配置文件是`~/.tmux.conf`，改完在会话里`tmux source-file ~/.tmux.conf`就生效，不用重启。我现在写的是：

```tmux
bind-key c new-window -c "#{pane_current_path}"
bind-key % split-window -h -c "#{pane_current_path}"
bind-key '"' split-window -c "#{pane_current_path"

# 让图片协议（kitty graphics / iTerm2 / sixel）穿过tmux传到外面的WezTerm
set -g allow-passthrough on
set -g visual-activity off
set -g focus-events on
```

那个`-c "#{pane_current_path}"`治的是"新窗口默认从`~`开始"，加上之后新窗口和新panel都沿用当前目录。

插件用[tpm](https://github.com/tmux-plugins/tpm)管（`prefix I`装、`prefix U`更新、`prefix alt-I`卸载），我装的是`tmux-sensible`、`tmux-resurrect`（`prefix C-s`存、`prefix C-r`取）和`tmux-continuum`（配`@tmux-continuum-restore on`，开机自动把上次的会话拉回来）

## 两个坑

- 新窗口/新panel默认从`~`开始，不是当前目录
- 新建窗口是`prefix c`，小写，我写成`prefix C`找过半天

想要挂载，先需要确认想挂载哪个，挂载了没：
```bash
lsblk -f
```
然后获取UUID:
```bash
sudo blkid
```
再创建挂载点，如`/mnt/data1`：
```bash
sudo mkdir /mnt/data1 -p
```
编辑fstab：
```bash
sudo vi /etc/fstab
```
添加一行：
```
UUID=980E115F0E113828 /mnt/data1 ntfs defaults 0 2
```

这六个字段依次是设备、挂载点、类型、选项、dump、pass。设备写UUID而不是`/dev/sdX`，因为后者会随插拔、启动顺序变；`defaults`是`rw,suid,dev,exec,auto,nouser,async`的缩写。后面两个数字里，dump现在基本没人用，写0；pass是开机fsck的顺序（0不检查、1先查根分区、2后查），NTFS我写的是0，因为Debian里没有`fsck.ntfs`，给它2没什么用，还可能因为盘不在把开机流程拖住。

基础的就不管了
常用基本指令：
- `r`：重新开始执行程序
- `s`：单步执行一行源代码，会进入函数
- `n`：单步执行一行源代码，不进入函数
- `finish`：执行到当前函数返回
- `p`：打印变量 / 寄存器
- `x`：扫描内存
- `bt`：查看调用栈
- `b` / `break`：设置断点
- `watch`：设置监视点
- `help <命令>`：查看命令的帮助

`layout`展示：
- `asm`：汇编码
- `reg`：寄存器
- `src`：源码

`c`继续、`until <行号>`跑到某行（跳过循环最省事）、`advance <函数>`跑到某个函数、`ni` / `si`是汇编层面的一行（不进 / 进）、`jump`直接跳到某行但会跳过中间的代码，慎用

## 用

```bash
gdb ./a.out                  # 调试
gdb ./a.out core             # 看core dump
gdb -p <pid>                 # attach到已经在跑的进程
gdb --args ./prog -x 1       # 带参数启动
gdb -batch -ex 'bt' -ex 'q' --args ./prog    # 脚本化
```

进去之后`set args`设参数、`start`跑到main、`attach` / `detach`中途上下的进程、`q`退出

## 断点

- `b file.c:100` / `b main`：文件行号或者函数名
- `b func if x == 0`：条件断点
- `tbreak`：只生效一次
- `rbreak ^log_`：按正则给一批函数下断点
- `info breakpoints`看列表，`delete <编号>` / `disable` / `enable`
- `condition <编号> x > 10`给已有断点加条件，`ignore <编号> 100`是前100次不停
- `commands <编号>`可以配一串命中时自动执行的命令，配`silent` + `bt` + `continue`就等于不打断程序、只偷偷记一份栈
- `watch x`是值变了就停（`rwatch`读、`awatch`读写、`watch -l x`盯地址），查"谁把这个指针改坏了"比在函数上打点精准

## 看数据

```gdb
p *ptr@10               # 打印ptr指的前10个元素，看数组/缓冲区很好用
p $rax / p $pc          # 寄存器当变量读
p (char*)$rdi           # 把寄存器当参数看
info registers / info locals / info args
x/16xb 0x7fffffffe000   # 从地址开始看16个字节
x/s $pc                 # 当成字符串看
x/10i $pc               # 反汇编接下来的10条
disassemble /m main     # 带源码的反汇编
display /i $pc          # 每次停下来自动显示，配undisplay关掉
```

`x`的语法是`x/[个数][格式][单位] 地址`，格式`x`十六进制、`d`十进制、`i`指令、`s`字符串，单位`b`是1字节、`h`是2、`w`是4、`g`是8

改的话就是`set var x = 5`、`set $rax = 0x1000`、`return 0`（直接从当前函数返回）

## 线程、信号、系统调用

- `info threads` / `thread <编号>` / `thread apply all bt`，死锁排查第一步
- `set follow-fork-mode child`、`set detach-on-fork off`
- `catch syscall write` / `catch signal SIGSEGV`
- `handle SIGPIPE nostop noprint pass`：别为这个信号停下来

## 远程 / 交叉调试

```bash
qemu-system-riscv32 ... -s -S     # -s开1234端口，-S先停住等gdb
```
```gdb
target remote :1234
file ./my.elf
load
```
交叉调试用`gdb-multiarch`（或者工具链自带的`riscv64-unknown-elf-gdb`），必要时`set architecture riscv:rv32`。ysyx里NEMU/NPC那套gdb客户端最后接的就是这里

## 其它

- `~/.gdbinit`里放常用的设置，`set pagination off`基本是必写的（不然每次翻页要按回车），`set print pretty on`让结构体好看点
- `dprintf main, "x=%d\n", x`：不下断点也能打日志
- `record` + `reverse-step` / `reverse-continue`：反向执行，慢，但查"值是哪一步变坏的"很好用
- 程序跑起来卡住的时候，`Ctrl-C`能中断它回到提示符
- `info line *$pc` / `info frame`能回答"这行到底是哪个文件哪一行"

# 在vim里面直接make

当然，我们完全可以`alt-I`打开终端直接编译，但比如有时候你就是不想多输入什么呢？直接`:make`然后在nvim当前窗口里面看信息岂不是更方便？
> RTFM
> 请参阅`:h :make`，当然更靠谱的是[Quickfix&:make](https://neovim.io/doc/user/quickfix/)，我觉得写的挺详细的

命令：`:make [arguments]`
1. 它会调用`{makeprg}`然后把后面的作为参数传入。首先`{makeprg}`当然可以不是GNU Make了，完全可以我们自己设定，比如gcc。
2. Quickfix
    可以直接定位到错误的地方，`c*`一般对应Quickfix List，而`l*`对应Location List

| 命令             | 功能                         |
| ---------------- | ---------------------------- |
| `:copen`         | 打开 Quickfix 窗口           |
| `:cclose`        | 关闭 Quickfix 窗口           |
| `:cnext` / `:cn` | 下一个错误                   |
| `:cprev` / `:cp` | 上一个错误                   |
| `:cfirst`        | 第一个错误                   |
| `:clast`         | 最后一个错误                 |
| `:cc`            | 跳转到当前错误               |
| `:cdo {cmd}`     | 对每个 Quickfix 条目执行命令 |

## 变量赋值

这块是最容易"看起来一样其实不一样"的地方：

- `A = $(B)`：递归展开，用到`$(A)`的时候才去看`$(B)`是什么
- `A := $(B)`：立即展开，定义这一行就把`$(B)`算出来
- `A ?= $(B)`：只有`A`没被定义过才赋值，适合给可以被命令行覆盖的默认值（`CFLAGS ?= -O2`）
- `A += $(B)`：追加，跟着`A`原本是哪种风格走

```makefile
B := old
A = $(B)
C := $(B)
B := new
all:
	echo $(A)	# new
	echo $(C)	# old
```

## 通配符

这块确实有点记不清...
当我们使用`*` / `%`这种正则表达匹配的方法是，往往需要用在一个`$(wildcard <regular_exp>)`里面使用

- `*`：就是匹配任意个字符。

  - 可以用在`wildcard` / `目标` / `prerequisites`里面
  - 不可以直接当作一个变量的定义！
  - 如果找不到，它就会被当作`*`这个字符！

- `%`：可以用于模式匹配 / 替换

  - Pattern rules:
    匹配任何非空字符串，如：

    ```makefile
    %.c:
    	touch $@
    ```

  - static pattern rule：

    比如：
    ```makefile
    objects = foo.o bar.o all.o
    all: $(objects)
    	$(CC) $^ -o all

    # Syntax - targets ...: target-pattern: prereq-patterns ...
    $(objects): %.o: %.c
    	$(CC) -c $^ -o $@

    all.c:
    	echo "int main() { return 0; }" > all.c

    # Note: all.c does not use this rule because Make prioritizes more specific matches when there is more than one match.
    %.c:
    	touch $@

    clean:
    	rm -f *.c *.o all
    ```

    这里的语法结构本身是：`targets : target-pattern: prereq-patterns`

  - 字符串替换：

    - `$(patsubst pattern, replacement, text)`
      这里就是从`text`里面找到用分割的符合`pattern`的词汇，然后把它们替换为`replacement`的形式
    - `$(<xx>: pattern=replacement)`：这里你甚至可以不需要`%`直接代表替换

    ```makefile
    foo	:=	a.o b.o c.o
    one	:=	$(patsubst %.o, %.c, $(foo))
    two := 	$(foo:%.o=%.c)
    three := $(foo:.o=.c)
    all:
    	echo $(one)
    	echo $(two)
    	echo $(three)
    ```

### 自动变量

- `$@`：目标名
- `$?`：所有比目标更新的prerequisite名
- `$^`：所有prerequisites名（去重）
- `$+`：和`$^`一样，但保留重复项
- `$<`：第一个prerequisite名
- `$*`：模式规则里匹配到`%`的那部分
- 还带目录/文件名的拆分：`$(@D)`是目标所在目录、`$(@F)`是目标文件名，`$(<D)` / `$(<F)`同理

### 常用函数

- `$(wildcard src/*.c)`：展开成实际存在的文件列表
- `$(patsubst %.c,%.o,$(SRC))` / `$(SRC:.c=.o)`
- `$(notdir ...)` / `$(dir ...)` / `$(basename ...)` / `$(suffix ...)`
- `$(addprefix build/, $(OBJ))` / `$(addsuffix .o, $(SRC))`
- `$(filter %.c,$(SRC))` / `$(filter-out %.c,$(SRC))`
- `$(firstword ...)` / `$(word 2,...)` / `$(words ...)`
- `$(shell git rev-parse --short HEAD)`：执行命令取输出，注意它只在变量被展开的时候跑，写在`=`定义的变量里会跑很多次，要用`:=`定下来
- `$(info ...)` / `$(warning ...)` / `$(error ...)`：打印信息，error会直接停下来

### 指令

- 不要显示这条指令：
  跑指令时，你可以在前面加上`@`告诉make不要显示这条指令
- 指定SHELL：
  默认是bash，但是你甚至可以自己指定
  `SHELL=/bin/bash`
- 错误处理：
  - 加一个`-k`：运行的时候即使有错误也要继续运行
  - 在命令最前面加上`-`：`suppress the error`压制错误不让它显示
  - 加一个`-i`：对全体都适用
- `.PHONY: all clean`：声明这些不是文件，不写的话万一目录里真有个叫`clean`的文件，`make clean`就会说"已经是最新的"然后什么都不干

### 包含
你可以包含别的`.mk`文件（这里面存储的是约束和规则，不会继承相关target）

```makefile
include config.mk
-include optional.mk     # 文件不存在也不报错
export PATH              # 导出给子make和命令
```

- `make -C dir`进子目录跑
- 用`$(MAKE)`递归调用子make（用`$(MAKE)`而不是`make`才能传参数）
- `$(CURDIR)`当前目录


## 调试

```bash
make -n            # 只打印将要执行的命令
make -p            # 打印make的"数据库"，所有变量和规则都在里面，配合grep查变量取值
make --debug=v     # 说明它为什么决定重建/跳过某个目标
make -B            # 无条件重建
```

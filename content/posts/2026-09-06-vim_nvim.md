vim 虽然是个文本编辑器，但其实还是挺复杂的...很多机制看了容易记不住，因此决定还是先整理一下以供之后检查。

## 命令

```vim
:%!grep "^\(gcc\|g++\)"
```
是的，你甚至可以在这里用终端命令！

- `:%!sort`：按行排序
- `:%!column -t`：对齐成整齐的表格
- `:'<,'>!clang-format`：只把选中的部分交给格式化工具
- `:r !date`：把命令的输出插到光标下面
- `:w !xclip -selection clipboard`：把当前缓冲区丢给剪贴板
- `:!make`：只执行命令，不动缓冲区


## 批量删行与替换

- `:g/pattern/d`：匹配的行全删掉
- `:g/pattern/normal dd`：对匹配的行执行普通模式命令（`normal` 后面可以接任意按键）
- `:v/keep/d`：不匹配 `keep` 的行删掉（`v` 就是 `g!`）
- `:%s/foo/bar/g`：全文替换
- `:%s/foo/bar/gc`：每次替换前问一下
- `:%s/\s\+$//e`：删掉行尾空格，`e` 表示"找不到也不算错"

## 寄存器、宏、撤销树

> 各种奇技淫巧都来自于寄存器...

- `"ayy`：把当前行存进 a 寄存器；`"ap` 贴出来
- `"_dd`：黑洞寄存器
- `"+y` / `"+p`：系统剪贴板
- `:registers`：看看现在各个寄存器里都是什么
- `qa ... q`：把一段操作录进 a 寄存器，`q` 结束录制
- `@a` 播放、`@@` 重复上一次播放、`5@a` 播放 5 次
- `u` / `C-r`：撤销 / 重做
- `g-` / `g+`：在撤销树的各个分支之间来回走（`:undolist` 看全部）


## 移动与文本对象

- `ciw`、`ci"`、`ci(`：改掉"一个词"、"引号里"、"括号里"的内容；`c` 换成 `d` 就是删
- `da"`、`di{`：`a` 是连分隔符一起，`i` 是只要里面的
- `gU` / `gu`：变大写 / 变小写，配 motion 用，比如 `gUiw`
- `%`：跳到匹配的括号
- `*` / `#`：向下 / 向上搜索光标下的词
- `g;` / `g,`：跳到上次 / 下次改动过的地方，改完想回头看特别有用

`. `（重复上一次改动）配 `cgn` 是"把后面几处一起改掉"最快的路径：`/目标` 回车，`cgn` 改第一处，之后一路按 `.`。

## 窗口、标签、跳转

- `:sp file` / `:vsp file`：横着 / 竖着分屏
- `C-w h/j/k/l`：在分屏之间跳
- `C-w =`：均分高度，`C-w _`：把当前窗口最大化
- `:tabnew` / `gt` / `gT`：新标签页 / 下一个 / 上一个
- `C-o` / `C-i`：按跳转历史往回 / 往前
- `:e .`：打开文件浏览器

## 别的什么玩意

- `A-i`：开一个浮动的终端

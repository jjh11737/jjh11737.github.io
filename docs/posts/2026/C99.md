## 关于宏

宏就是给预处理器 / 编译器处理的，因此行为也会和编译器有关

1. **可变参数宏：**
```c
#define Log(format, ...) \
```
C99开始就引入了可变参数宏，这里我们使用时就可以写:
```c
Log("%d", x);
```
2. **预定义宏：**

   | 宏/标识符                  | 描述                                                                   | 谁替换/提供 |
   | -------------------------- | ---------------------------------------------------------------------- | ----------- |
   | `__DATE__`                 | 编译日期，字符串字面量，形如 `"Sep  6 2026"`（`dd` 不足 10 时前面补空格） | 预处理器    |
   | `__LINE__`                 | 当前源代码行号，整数常量（可被 `#line` 改变）                          | 预处理器    |
   | `__FILE__`                 | 当前源文件名，字符串字面量（可被 `#line` 改变）                        | 预处理器    |
   | `__TIME__`                 | 编译时间，字符串字面量，形如 `"23:59:01"`                              | 预处理器    |
   | `__STDC__`                 | 展开为整数常量 `1`，表示实现符合 ISO C                                 | 预处理器    |
   | `__STDC_VERSION__`         | 实现支持的 C 标准版本号（`long` 类型）；C99 为 `199901L`               | 预处理器    |
   | `__STDC_HOSTED__`          | 宿主环境为 `1`，独立（freestanding）环境为 `0`                         | 预处理器    |
   | `__STDC_IEC_559__`         | 若支持 IEC 60559 浮点运算，定义为 `1`（可选）                          | 预处理器    |
   | `__STDC_IEC_559_COMPLEX__` | 若支持 IEC 60559 复数运算，定义为 `1`（可选）                          | 预处理器    |
   | `__STDC_ISO_10646__`       | 若 `wchar_t` 使用 Unicode，展开为形如 `yyyymmL` 的整数常量（表示所支持的 Unicode 版本），否则未定义（可选） | 预处理器    |
   | `__STDC_MB_MIGHT_NEQ_WC__` | 若基本字符集里可能出现 `'x' != L'x'`（如 EBCDIC 系统），定义为 `1`（可选） | 预处理器    |
   | `__func__`                 | 当前函数名，C99 引入的函数局部预定义标识符（不是宏）                   | 编译器      |
   | `__OBJC__`                 | Objective-C 编译器扩展宏，使用 Objective-C 时通常定义                  | 编译器扩展  |
   | `__cplusplus`              | C++ 编译器扩展宏；使用 C++ 时定义，值表示语言版本                      | 编译器扩展  |

   这些很有用！就比如说我们可以结合`__LINE__`和`__FILE__`来进行错误处理和反馈：（这是NEMU里面的，`_Log`是一个函数，你可以用`printf`代替，这里封装一下只是为了同时写入`.log`文件）
   ```c
   #define Log(format, ...) \
       _Log(ANSI_FMT("[%s:%d %s] " format, ANSI_FG_BLUE) "\n", \
           __FILE__, __LINE__, __func__, ## __VA_ARGS__)
   ```
   
   
   
   
   
   [GNU专门的预定义宏](https://gcc.gnu.org/onlinedocs/cpp/Common-Predefined-Macros.html)
   
   甚至还有特定系统对应的宏，就比如 ISA / kernel 相关的信息，我们只需要检查对应的宏有没有定义就好了！
